# Watermelon Soda POS

A multi-outlet point-of-sale prototype for a refreshing beverage company.

## Features

- **Employee Login**: PIN-based authentication for cashiers and managers
- **POS Interface**: Quick product selection and order management
- **Multiple Outlets**: Track sales across different store locations
- **Payment Methods**: Support for cash, card, and QR payments
- **Owner Dashboard**: Real-time sales analytics and outlet performance
- **Local Storage**: All data persists in the browser

## How to Use

1. Open the application in your browser
2. Select "Employee" or "Owner" tab
3. Log in with credentials above
4. **Employee Mode**: Add products to cart, select payment method, complete sale
5. **Owner Mode**: View daily sales analytics by outlet

## Technical Stack

- **Frontend**: Vanilla JavaScript, HTML5, CSS3
- **Storage**: Browser localStorage (no backend)
- **Responsive**: Mobile and tablet optimized

## Limitations

⚠️ **Prototype Only** — This is a demonstration of the UI/UX. For production use, you need:
- Secure backend authentication
- Cloud database (not localStorage)
- Payment gateway integration
- Data encryption and compliance
- Multi-user session management
- Audit logging
